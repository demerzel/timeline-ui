Timeline UI Component

A vanilla JavaScript component for navigating time-based content

Demo Actions:

Features

  • Multiple Zoom Levels: Switch between months, years, and decades views
  • Windowed Viewing: Shows a limited number of items at once for performance
  • Smooth Scrolling: Navigate through time with mouse wheel, keyboard, or controls
  • Responsive Design: Works on desktop and mobile devices
  • Type Support: Different visual styles for events, photos, and posts
  • Custom Scrollbar: Visual indicator of position in timeline

Keyboard Shortcuts

  • ↑ / ↓ - Scroll up/down one item
  • ← / → - Navigate to previous/next time period

Usage

  • Use the zoom buttons to change the time granularity
  • Click Previous/Next to jump between time periods
  • Scroll with mouse wheel or drag the scrollbar
  • Click on any timeline item to interact with it
