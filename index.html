Timeline UI Component

A vanilla JavaScript component for navigating time-based content

Zero Dependencies Responsive Accessible Dark Mode

Demo Actions

Key Features

Multiple Zoom Levels

Switch between months, years, and decades views seamlessly

Windowed Viewing

Efficiently handles 1000+ items with virtual scrolling

Smooth Navigation

Mouse wheel, keyboard shortcuts, and touch support

Responsive Design

Works beautifully on desktop, tablet, and mobile

Type System

Built-in support for events, photos, posts, and custom types

Zero Dependencies

Pure vanilla JavaScript, no frameworks required

Keyboard Shortcuts

  • ↑ / ↓ - Scroll up/down one item
  • ← / → - Navigate to previous/next time period

Quick Start

  • Use the zoom buttons above to change time granularity
  • Click Previous/Next to jump between time periods
  • Scroll with mouse wheel or drag the scrollbar on the right
  • Click on any timeline item to see details
  • Try the demo actions to add items and navigate
